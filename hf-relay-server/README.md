# Creative Engine Relay Server

Lightweight WebSocket relay for real-time collaboration in Creative Engine.

## Deployment

To deploy this on Hugging Face:
1. Create a new Space.
2. Choose **Docker** as the SDK.
3. Upload the contents of this directory (`Dockerfile`, `server.js`, `package.json`).
4. Wait for the build to finish.
5. Use your Space URL (e.g., `https://your-user-ce-relay.hf.space`) in the engine's Project Settings.
