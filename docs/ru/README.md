# 🎨 Creative Engine - Документация

Добро пожаловать в официальную документацию **Creative Engine**, мощного и доступного 2D-игрового движка, предназначенного для создания игр прямо в вашем браузере.

Creative Engine сочетает в себе визуальную простоту с профессиональной системой скриптинга, позволяя вам воплощать свои идеи в жизнь без сложных инсталляций.

## 🚀 Быстрый старт

1.  **Создайте Материю**: Щелкните правой кнопкой мыши в **Иерархии** и выберите тип объекта.
2.  **Добавьте Закон**: Выбрав объект, перейдите в **Инспектор** и нажмите "Добавить Закон".
3.  **Запрограммируйте логику**: Создайте файл `.ces` в **Браузере**, откройте его и начните писать.
4.  **Протестируйте свою игру**: Нажмите кнопку **Play** и увидите свое творение в действии.
