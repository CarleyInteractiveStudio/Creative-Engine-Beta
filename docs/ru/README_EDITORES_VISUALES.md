# 🎨 Руководство по визуальным редакторам - Creative Engine

Creative Engine включает набор визуальных инструментов для интуитивного управления графикой и анимацией.

---

## ✂️ 1. Редактор спрайтов (Sprite Slicer)

Позволяет разрезать большое изображение на несколько маленьких спрайтов.

- **Как открыть:** Дважды щелкните по любому изображению (.png, .jpg) в Браузере активов.

---

## 🎞️ 2. Редактор анимаций (.cea)

Создавайте последовательности изображений для ваших персонажей.

- **Как открыть:** Дважды щелкните по файлу `.cea`.
