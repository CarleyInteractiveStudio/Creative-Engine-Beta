# Горячие клавиши редактора - Creative Engine

В этом документе описаны горячие клавиши, доступные для ускорения рабочего процесса в редакторе.

## Общие
- **Ctrl + S**: Сохранить текущую Сцену (или Скрипт, если активен редактор кода).
- **Ctrl + O**: Открыть Сцену.
- **Ctrl + D**: Дублировать выбранную Материю.
- **Delete / Backspace**: Удалить выбранную Материю.

## Инструменты сцены
- **Q**: Инструмент перемещения.
- **W**: Инструмент панорамирования (Камера).
- **E**: Инструмент масштабирования.
- **R**: Инструмент вращения.
- **T**: Универсальный инструмент.
- **B**: Кисть ландшафта / тайлов.
- **G**: Заливка (Тайлы).
- **N**: Ластик (Тайлы).

## Окна (Быстрые клавиши)
- **Ctrl + N**: Создать новую пустую Материю в сцене.
- **Ctrl + Shift + A**: Открыть редактор анимации.
- **Ctrl + Shift + C**: Открыть контроллер анимации (Animator).
- **Ctrl + Shift + S**: Открыть редактор спрайтов / Slicer.
- **Ctrl + Shift + L**: Открыть/закрыть чат с Carl ИИ.
- **Ctrl + Shift + B**: Открыть окно библиотек.

## Редактор кода
- **Ctrl + Z**: Отменить.
- **Ctrl + Y**: Повторить.
