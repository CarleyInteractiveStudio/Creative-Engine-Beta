# ⚙️ Руководство по настройке и окружению - Creative Engine

Это руководство объясняет, как настроить рабочий процесс в редакторе и технические параметры вашего проекта.

---

## 🛠️ 1. Настройки проекта

Доступ через **Правка > Настройки проекта**.

- **Метаданные:** Измените название игры, версию и автора.
- **Слои (Layers):** Определите порядок отрисовки и коллизий.

---

## 🎨 2. Предпочтения редактора

Доступ через **Правка > Настройки**.

- **Язык:** Переключение интерфейса между испанским и английским.
- **Темы:** Выбор визуальных тем.
