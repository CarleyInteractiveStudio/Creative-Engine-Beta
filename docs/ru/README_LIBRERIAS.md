# 📚 Руководство по библиотекам и расширяемости - Creative Engine

Библиотеки в Creative Engine (файлы `.celib`) позволяют расширять как интерфейс редактора, так и возможности программирования ваших игр.

---

## 🛠️ 1. Библиотеки интерфейса

Вы можете создавать свои собственные окна и инструменты для редактора с помощью `CreativeEngine.API`.

---

## 🎮 2. Библиотеки времени выполнения (Runtime)

Если вы хотите добавить новые функции для использования в скриптах `.ces`, вам нужно зарегистрировать API.

### Пример: Библиотека математики

```javascript
(function() {
    const МойКалькулятор = {
        sumar: (a, b) => a + b
    };
    CreativeEngine.API.registrarRuntimeAPI("МойКалькулятор", МойКалькулятор);
})();
```

### Использование в скрипте (.ces)

```ces
двигатель motor;
go "МойКалькулятор";

начать() {
    любой результат = sumar(10, 5);
    log("Результат: " + результат);
}
```
