# 🖥️ Руководство по терминалу - Creative Engine

Терминал — это продвинутый инструмент, позволяющий взаимодействовать с движком с помощью текстовых команд.

---

## 🚀 Как активировать терминал

1. **Верхнее меню:** Перейдите в **Окно > Терминал**.
2. **Нижняя вкладка:** На панели Активов/Консоли нажмите вкладку **Терминал**.

---

## 📂 1. Команды файловой системы

- `ls`: Список всех файлов и папок.
- `cd <папка>`: Войти в папку.
- `pwd`: Показать текущий путь.

---

## 🎬 2. Команды сцены

- `lsobj`: Список всех объектов на сцене.
- `mkobj <имя>`: Создать новую пустую Материю.
- `rmobj <id>`: Удалить объект.
