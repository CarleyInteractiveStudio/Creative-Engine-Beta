# 📜 Мастер-руководство по скриптингу (CES) - Creative Engine

Creative Engine использует **CES (Creative Engine Script)** — мощный язык, основанный на JavaScript, но упрощенный для создателей игр. Это руководство научит вас всему: от основ до сложных систем.

---

## 🚀 Основные концепции

### 1. Обязательный импорт
Каждый скрипт должен начинаться с инструкции для подключения к движку:
```ces
двигатель motor;
```
*(Примечание: вы также можете использовать `ve motor;`, так как это псевдоним)*

### 2. Прямой доступ (без префиксов)
В отличие от других движков, вам НЕ нужно писать `this.` или `mtr.` для доступа к компонентам объекта. Если у объекта есть `SpriteRenderer`, просто напишите `рендерСпрайта`.

---

## 💎 Публичные переменные (Инспектор)
Чтобы переменная появилась в Инспекторе редактора, используйте ключевое слово `открытый`.

```ces
открытый число скорость = 5;
открытый текст имяИгрока = "Герой";
открытый булево неуязвим = ложь;
открытый материя цель; // Появится поле для перетаскивания объектов
открытый спрайт иконка;
открытый аудио звукПрыжка;
```

## ⏱️ События жизненного цикла
Это функции, которые движок вызывает автоматически в определенные моменты.

```ces
// Выполняется один раз, когда объект появляется в игре
начать() {
    log("Привет, мир!");
}

// Выполняется каждый кадр (примерно 60 раз в секунду)
обновить(delta) {
    // delta - это время, прошедшее с прошлого кадра
}

// Выполняется через фиксированные интервалы (идеально для физики)
actualizarFijo(delta) {
}

// Выполняется при клике на объект
alHacerClick() {
}
```

## ⌨️ Ввод (Input) и движение
Управляйте вашими персонажами легко.

```ces
обновить(delta) {
    // Клавиша нажата (удерживается)
    если (teclaPresionada("d")) {
        позиция.x += скорость;
        отразитьГ = ложь;
    }

    // Клавиша только что нажата (одиночный импульс)
    если (teclaRecienPresionada("Space") и estaTocandoTag("Земля")) {
        физика.applyImpulse(новый Vector2(0, -10));
    }

    // Мышь
    если (botonMouseRecienPresionado(0)) { // 0: Левая, 1: Средняя, 2: Правая
        любой posMouse = obtenerPosicionMouse();
        log("Клик в: " + posMouse.x + ", " + posMouse.y);
    }
}
```

## 🪄 Специальные функции Creative Engine

### ⏳ Корутины (Ожидание)
Позволяет приостановить логику скрипта, не замораживая игру.
```ces
начать() {
    log("Начало отсчета...");
    ждать(3);
    log("ПУСК!");
}
```

### 🔁 Временные циклы (Каждый)
Выполняет что-то повторно каждые X секунд.
```ces
начать() {
    cada(1.5) {
        log("Прошло полторы секунды");
        // Идеально для спавна врагов или регенерации здоровья
    }
}
```
