# 🤖 Руководство по Carl ИИ: Ваш автономный помощник - Creative Engine

Carl ИИ — это не просто чат; это интеллектуальный агент, способный управлять редактором, создавать файлы и помогать вам собирать игру шаг за шагом.

---

## 🚀 Как активировать Carl ИИ

1. **Верхняя кнопка:** Нажмите на иконку робота 🤖 (**Carl**) в строке меню.
2. **Горячие клавиши:** Нажмите `Shift + Ctrl + L`.

---

## 🛠️ Автономные способности

Вы можете попросить Carl выполнить реальные задачи в вашем проекте:

- *"Создай объект под названием Игрок с SpriteRenderer и Rigidbody2D."*
- *"Создай скрипт, который перемещает игрока стрелками."*
