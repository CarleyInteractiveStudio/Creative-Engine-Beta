# 🏗️ 高级指南：项目、场景和构建 - Creative Engine

本指南涵盖了资源管理、关卡设计和游戏最终发布的各个方面。

---

## 📂 1. 项目结构

Creative Engine 中的每个项目都保存在一个独立的文件夹中：
- `/Assets`: 存放所有图像、声音、视频和脚本。
- `/lib`: 存放扩展引擎功能的库 (.celib)。
- `project.ceconfig`: 技术配置文件。

---

## 🎬 2. 场景管理 (.ceScene)

场景是包含物质和环境设置的独立世界。

---

## 🏗️ 3. 构建系统 (Build)

构建过程会生成一个独立的 Web 包 (`.zip`)，可以部署到服务器上。

1. 前往 **文件 > Build**。
2. 选择初始场景。
3. 点击“构建游戏”。
