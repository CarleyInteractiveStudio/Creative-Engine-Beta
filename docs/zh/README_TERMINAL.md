# 🖥️ 终端指南 - Creative Engine

终端是一个高级工具，允许通过文本命令与引擎交互。

---

## 🚀 如何激活终端

在编辑器中打开终端有两种方式：
1. **顶部菜单：** 前往 **窗口 > 终端**。
2. **底部标签：** 在资源/控制台面板中，点击 **终端** 标签。

---

## 📂 1. 文件系统命令

- `ls`: 列出所有文件和文件夹。
- `cd <文件夹>`: 进入文件夹。
- `pwd`: 显示当前路径。

---

## 🎬 2. 场景命令

- `lsobj`: 显示当前场景中所有对象的列表。
- `mkobj <名称>`: 创建一个新的空物质。
- `rmobj <id>`: 删除对象。
