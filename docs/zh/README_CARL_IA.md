# 🤖 Carl IA 指南：您的自主助手 - Creative Engine

Carl IA 不仅仅是一个聊天机器人；它是一个智能代理，能够操作编辑器、创建文件并帮助您一步步构建游戏。

---

## 🚀 如何激活 Carl IA

1. **顶部按钮：** 点击菜单栏中的机器人图标 🤖 (**Carl**)。
2. **快捷键：** 按 `Shift + Ctrl + L`。

---

## 🛠️ 自主能力

您可以要求 Carl 在您的项目中执行实际任务：

- *"创建一个名为 Player 的对象，带有 SpriteRenderer 和 Rigidbody2D。"*
- *"创建一个脚本，使用箭头键移动玩家。"*
