# 🧩 组件指南（法律） - Creative Engine

在 Creative Engine 中，**物质**（对象）通过**法律**（组件）获得生命。

---

## 🏗️ 1. 核心组件

### 📍 Transform（变换）
定义对象的位置、旋转和缩放。
- **脚本编写：**
  ```ces
  位置.x += 5; // 向右移动
  ```

---

## ⚙️ 2. 2D 物理

### ⚖️ Rigidbody2D（物理）
允许对象对重力和碰撞做出反应。
- **脚本编写：**
  ```ces
  物理.applyImpulse(新建 向量2(0, -10)); // 跳跃
  ```
