# 🎨 Creative Engine - 文档

欢迎来到 **Creative Engine** 的官方文档。这是一款强大且易于使用的 2D 游戏引擎，旨在让您直接在浏览器中进行创作。

Creative Engine 将视觉上的简洁性与专业的脚本系统相结合，让您无需复杂的安装即可将您的创意变为现实。

## 🚀 快速开始

1.  **创建物质**：在**层级面板**中右键点击并选择一种对象类型。
2.  **添加法律**：选中对象后，前往**检查器**并点击“添加法律”。
3.  **编写逻辑**：在**浏览器**中创建一个 `.ces` 文件，打开它并开始编写。
4.  **测试游戏**：按下 **Play** 按钮，查看您的创作成果。
