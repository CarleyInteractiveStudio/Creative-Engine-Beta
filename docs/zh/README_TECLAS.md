# 编辑器键盘快捷键 - Creative Engine

本文档详细介绍了编辑器中可用于加速工作流程的键盘快捷键。

## 常规
- **Ctrl + S**: 保存当前场景（如果代码编辑器激活，则保存脚本）。
- **Ctrl + O**: 打开场景。
- **Ctrl + D**: 复制选中的物质。
- **Delete / Backspace**: 删除选中的物质。

## 场景工具
- **Q**: 移动工具。
- **W**: 平移工具（摄像机）。
- **E**: 缩放工具。
- **R**: 旋转工具。
- **T**: 通用工具。
- **B**: 地形/瓦片画笔。
- **G**: 油漆桶（瓦片）。
- **N**: 橡皮擦（瓦片）。

## 窗口（快速快捷键）
- **Ctrl + N**: 在场景中创建新的空物质。
- **Ctrl + Shift + A**: 打开动画编辑器。
- **Ctrl + Shift + C**: 打开动画控制器 (Animator)。
- **Ctrl + Shift + S**: 打开精灵编辑器 / 切割器。
- **Ctrl + Shift + L**: 打开/关闭与 Carl IA 的聊天。
- **Ctrl + Shift + B**: 打开库窗口。

## 代码编辑器
- **Ctrl + Z**: 撤销。
- **Ctrl + Y**: 重做。
