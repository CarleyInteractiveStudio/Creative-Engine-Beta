# Atalhos de Teclado do Editor - Creative Engine

Este documento detalha os atalhos de teclado disponíveis para agilizar seu fluxo de trabalho no editor.

## Geral
- **Ctrl + S**: Salvar Cena atual (ou Script se o editor de código estiver ativo).
- **Ctrl + O**: Abrir Cena.
- **Ctrl + D**: Duplicar Matéria selecionada.
- **Delete / Backspace**: Excluir Matéria selecionada.

## Ferramentas de Cena
- **Q**: Ferramenta de Movimentação.
- **W**: Ferramenta de Pan (Câmera).
- **E**: Ferramenta de Escala.
- **R**: Ferramenta de Rotação.
- **T**: Ferramenta Universal.
- **B**: Pincel de Terreno / Tiles.
- **G**: Balde de Tinta (Tiles).
- **N**: Borracha (Tiles).

## Janelas (Atalhos Rápidos)
- **Ctrl + N**: Criar Nova Matéria Vazia na cena.
- **Ctrl + Shift + A**: Abrir Editor de Animação.
- **Ctrl + Shift + C**: Abrir Controlador de Animação (Animator).
- **Ctrl + Shift + S**: Abrir Editor de Sprites / Slicer.
- **Ctrl + Shift + L**: Abrir/Fechar Chat com Carl IA.
- **Ctrl + Shift + B**: Abrir Janela de Bibliotecas.

## Editor de Código
- **Ctrl + Z**: Desfazer.
- **Ctrl + Y**: Refazer.
