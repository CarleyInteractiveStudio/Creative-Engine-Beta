# 🎨 Creative Engine - Documentação

Bem-vindo à documentação oficial do **Creative Engine**, um motor de jogo 2D poderoso e acessível projetado para criar diretamente do seu navegador.

O Creative Engine combina simplicidade visual com um sistema de scripting profissional, permitindo que você dê vida às suas ideias sem instalações complexas.

## 🚀 Início Rápido

1.  **Criar uma Matéria**: Clique com o botão direito na **Hierarquia** e selecione um tipo de objeto.
2.  **Adicionar uma Lei**: Com o objeto selecionado, vá ao **Inspetor** e clique em "Adicionar Lei".
3.  **Programar a Lógica**: Crie um arquivo `.ces` no **Navegador**, abra-o e comece a escrever.
4.  **Testar seu Jogo**: Pressione o botão **Play** e veja sua criação em ação.
