# Editor Keyboard Shortcuts - Creative Engine

This document details the keyboard shortcuts available to speed up your workflow in the editor.

## General
- **Ctrl + S**: Save current Scene (or Script if code editor is active).
- **Ctrl + O**: Open Scene.
- **Ctrl + D**: Duplicate selected Matter.
- **Delete / Backspace**: Remove selected Matter.

## Scene Tools
- **Q**: Move Tool.
- **W**: Pan Tool (Camera).
- **E**: Scale Tool.
- **R**: Rotate Tool.
- **T**: Universal Tool.
- **B**: Terrain / Tiles Brush.
- **G**: Paint Bucket (Tiles).
- **N**: Eraser (Tiles).

## Windows (Quick Shortcuts)
- **Ctrl + N**: Create New Empty Matter in the scene.
- **Ctrl + Shift + A**: Open Animation Editor.
- **Ctrl + Shift + C**: Open Animator Controller.
- **Ctrl + Shift + S**: Open Sprite Editor / Slicer.
- **Ctrl + Shift + L**: Open/Close Chat with Carl AI.
- **Ctrl + Shift + B**: Open Libraries Window.

## Code Editor
- **Ctrl + Z**: Undo.
- **Ctrl + Y**: Redo.
