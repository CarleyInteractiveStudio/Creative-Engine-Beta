# 🎨 Creative Engine - Documentation

Welcome to the official documentation of **Creative Engine**, a powerful and accessible 2D game engine designed to create directly from your browser.

Creative Engine combines visual simplicity with a professional scripting system, allowing you to bring your ideas to life without complex installations.

## 🚀 Quick Start

1.  **Create a Matter**: Right-click in the **Hierarchy** and select a type of object.
2.  **Add a Law**: With the object selected, go to the **Inspector** and click "Add Law".
3.  **Program the Logic**: Create a `.ces` file in the **Browser**, open it, and start writing.
4.  **Test your Game**: Press the **Play** button and see your creation in action.
