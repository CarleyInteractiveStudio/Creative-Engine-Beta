# Carl CHC - Hugging Face Space

Este es el servidor para **CHC** (Code Helper) de Creative Engine.

## Cómo usar
1. Crea un nuevo Space en Hugging Face (Docker).
2. Sube estos archivos.
3. El Space se ejecutará en una CPU gratuita de Hugging Face.
4. Una vez activo, copia la URL y pégala en la configuración de CHC en el motor.

## Características
- Modelo: DeepSeek-Coder 1.3B Instruct.
- Especializado en generación de código.
- Sistema de cola para evitar sobrecarga.
