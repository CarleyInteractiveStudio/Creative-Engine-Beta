# Creative Engine 🎨🚀

Добро пожаловать в центр знаний **Creative Engine**! Здесь вы найдете всё необходимое, чтобы превратить ваши идеи в интерактивную реальность. Наша документация призвана стать вашим верным спутником — от первых шагов до запуска вашего масштабного проекта.

---

## 📚 Разделы документации

### 📕 [Книга Мастера Скриптов (CES)](README_SCRIPTING.md)
**Наша жемчужина.** Полное руководство из 12 глав, которое научит вас программировать с нуля на мощном языке CES. Включает:
- Базовые концепции и философию.
- Полный справочник API.
- **Cookbook:** Готовые рецепты кода (движение, стрельба, UI).
- Руководство по оптимизации.

### 🧩 [Руководство по компонентам (Leyes)](README_COMPONENTES.md)
Подробный словарь всех «Законов» (Leyes), которые вы можете применить к своим объектам:
- Физика и коллизии.
- Рендеринг спрайтов и видео.
- Контроллеры транспорта (вертолеты, самолеты, машины).
- Системы 2D-освещения.

### 🎨 [Руководство по визуальным редакторам](README_EDITORES_VISUALES.md)
Научитесь использовать мощные встроенные визуальные инструменты:
- **Редактор анимаций:** Создавайте плавные последовательности.
- **Редактор тайлмапов:** Стройте уровни на основе сеток.
- **VidSpri:** Секрет превращения видео в легкие спрайты.

### 📚 [Книга по расширяемости (Библиотеки)](README_LIBRERIAS.md)
**Для архитекторов инструментов.** Научитесь создавать собственные окна в редакторе и расширять функции скриптов с помощью чистого JavaScript (.celib).

### 🤖 [Мануал по Carl IA](README_CARL_IA.md)
Узнайте, как работать плечом к плечу с Carl — вашим интеллектуальным помощником, способным строить сцены и писать код за вас, используя естественный язык.

### ⚙️ [Продвинутое управление и конфигурация](README_AVANZADO.md)
Для разработчиков, которые хотят пойти дальше:
- Создание и управление префабами.
- Система билда и экспорт.
- Глобальная конфигурация проекта и слои.

---

## 🚀 С чего начать?

Если вы новичок, мы рекомендуем придерживаться следующего порядка:
1. Прочтите **Главу 0** [Книги Мастера Скриптов](README_SCRIPTING.md), чтобы увидеть свой первый работающий код.
2. Изучите [Руководство по компонентам](README_COMPONENTES.md), чтобы понять, на что способен ваш объект.
3. Начинайте творить и получайте удовольствие!
