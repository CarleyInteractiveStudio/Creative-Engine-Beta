# 📟 Команды терминала - Creative Engine

Терминал — это продвинутый инструмент для отладки и управления движком. Доступ: **Окно > Терминал**.

---

## 📂 Управление файлами
- `ls [папка]`: Список содержимого.
- `cd [папка]`: Смена директории.
- `mkdir [имя]`: Создать папку.

---

## 🔍 Инспекция объектов
- `find [имя]`: Найти объект на сцене и получить его ID.
- `inspect [id]`: Показать свойства объекта в JSON.

---

## 🎮 Управление игрой
- `play`: Запустить игру.
- `stop`: Остановить и вернуть сцену.
- `scene [путь]`: Немедленная загрузка сцены.
