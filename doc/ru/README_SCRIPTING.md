В этой цифровой «книге» мы изучим всё: от основ логики до самых продвинутых архитектур. Приготовься, потому что **программировать проще, чем ты думаешь, и здесь мы докажем тебе почему**.

## ⚡ Глава 0: Твой первый скрипт за 60 секунд

Хочешь увидеть результат прямо сейчас? Следуй этим шагам:

1. В **Браузере активов (Asset Browser)** нажми правую кнопку мыши и выбери **Новый > Скрипт (CES)**. Назови его `HelloWorld.ces`.
2. Дважды кликни, чтобы открыть его, и вставь этот код:
```ces
ve motor;

alEmpezar() {
    imprimir("Движок ожил!");
}

alActualizar(delta) {
    rotacion += 100 * delta; // Это заставит объект вращаться!
}
```
3. Перетащи этот файл из библиотеки на любой объект (изображение или квадрат) в твоей сцене.
4. Нажми **Play**! 🚀

## 🏛️ Глава 1: Философия движка

Creative Engine родился с одной целью: **Код должен быть читаемым для людей и мощным для машин.**

В отличие от других движков, которые заставляют тебя иметь дело с тысячами строк «мусорного кода» (boilerplate), в CES важна каждая строка. Мы убрали необходимость использовать `this.`, `mtr.` или избыточные префиксы. Если у объекта есть здоровье, просто напиши `health`. Если хочешь его переместить, напиши `posicion` или `position`.

**Цель состоит в том, чтобы твой код выглядел как описание того, что ты хочешь сделать.**

## 🦴 Глава 2: Анатомия скрипта

Каждый скрипт в Creative Engine начинается с объявления намерения:

```ces
ve motor;
```

Эта строка обязательна; это мост, соединяющий твой текстовый файл с сердцем движка. С этого момента твой скрипт становится «Законом», который управляет поведением «Материи» (объекта).

## 💎 Глава 3: Переменные и динамический инспектор

Сила Creative Engine заключается в его **Инспекторе**. Объявляя переменные как `publico` (публичные), они магическим образом появляются в интерфейсе редактора, позволяя тебе настраивать игру прямо во время её работы.

### Поддерживаемые типы данных:
- **`number` (число)**: Для скорости, силы, здоровья и т. д.
- **`text` (текст)**: Для имен, диалогов или ID.
- **`boolean` (булево)**: Переключатели «истина» или «ложь».
- **`Materia` (Материя)**: Для ссылок на другие объекты в сцене.
- **`Prefab` (Префаб)**: Для создания новых объектов (например, пуль или врагов).
- **`Audio` / `Sprite` / `Scene`**: Ссылки на ресурсы проекта.

```ces
publico число силаПрыжка = 12;
publico булево можетЛетать = ложь;
publico Материя целеваяКамера;
```

## ⏱️ Глава 4: Ритм игры (Жизненный цикл)

Игра — это иллюзия, созданная быстро сменяющимися изображениями. Твой скрипт живет внутри этого сердцебиения:

1. **`начать()` / `alEmpezar()`**: Твоя золотая возможность настроить объект. Выполняется только один раз.
2. **`обновить(delta)` / `alActualizar(delta)`**: Происходит примерно 60 раз в секунду. Здесь ты обрабатываешь движение и постоянную логику.
3. **`actualizarFijo(delta)`**: Здесь работает физический движок. Используй его для постоянных сил, чтобы объекты не «проходили сквозь» стены.
4. **`alHacerClick()`**: Прямой ответ на касание игрока.

## ⌨️ Глава 5: Полное взаимодействие (Ввод и физика)

Движок понимает твои команды естественным образом. Будь то клавиатура, мышь или геймпад, API везде одинаков:

```ces
обновить(delta) {
    // Клавиатура
    если (teclaPresionada("w")) {
        физика.applyForce(0, -100);
    }

    // Мышь
    если (botonMouseRecienPresionado(0)) {
        variable поз = obtenerPosicionMouse();
        imprimir("Клик в: " + поз.x + "," + поз.y);
    }
}
```

## 📦 Глава 6: Словарь компонентов (Справочник API)

Вот самые распространенные ярлыки, которые движок дает тебе бесплатно:

- **`posicion` (Трансформ)**: ДНК объекта. Управляет `x`, `y`, `вращением` и `масштабом`.
- **`физика` (Rigidbody2D)**: Двигатель Ньютона. Используй `applyImpulse` для прыжков и `velocity` для бега.
- **`zdorovye` (Здоровье)**: Управление смертностью. Используй `damage(10)` или `heal(5)`.
- **`аниматор` (Animator)**: Кинорежиссер. Используй `play("Run")` для смены состояний.
- **`аудио` (AudioSource)**: Голос объекта. Используй `play()` или `stop()`.

## 📡 Глава 7: Связь между объектами (Глобальные сообщения)

Забудь о поиске объектов по всей иерархии. Система **глобальных сообщений** позволяет твоим скриптам разговаривать друг с другом, не зная друг друга.

**Отправитель:**
```ces
broadcast("LevelCompleted", { time: 45 });
```

**Получатель:**
```ces
onReceive("LevelCompleted", (данные) => {
    imprimir("Поздравляем! Вы прошли уровень за " + данные.time + " секунд.");
});
```

## 🪄 Глава 8: Магия времени (Корутины и циклы)

### Искусство ожидания (`ждать`)
В CES ты можешь приостановить логику скрипта, не замораживая игру. Это жизненно важно для кат-сцен или эффектов.

```ces
async начать() {
    imprimir("3...");
    ждать(1);
    imprimir("2...");
    ждать(1);
    imprimir("1...");
    ждать(1);
    imprimir("ОГОНЬ!");
}
```

### Сила повторения (`cada`)
Тебе нужно создавать монету каждые 5 секунд? Не используй сложные ручные счетчики:

```ces
начать() {
    cada(5) {
        create coinPrefab;
    }
}
```

## 🍳 Глава 9: Книга рецептов (Cookbook)

### 🏃 Профессиональная система движения для платформ
```ces
ve motor;
publico число скорость = 300;
publico число силаПрыжка = 15;

обновить(delta) {
    variable horizontal = 0;
    если (teclaPresionada("d")) horizontal = 1;
    если (teclaPresionada("a")) horizontal = -1;

    физика.velocity.x = horizontal * (скорость * delta);

    если (horizontal != 0) {
        отразитьГ = (horizontal < 0);
        воспроизвести.Walk();
    } иначе {
        воспроизвести.Idle();
    }

    если (teclaRecienPresionada("Space") и estaTocandoTag("Ground")) {
        физика.applyImpulse(новый Vector2(0, -силаПрыжка));
    }
}
```

### 🎯 Система стрельбы с кулдауном
```ces
ve motor;
publico Префаб пуля;
publico число скорострельность = 0.5;
число времяДоСледующегоВыстрела = 0;

обновить(delta) {
    если (teclaPresionada("f") и времяДоСледующегоВыстрела <= 0) {
        create пуля;
        времяДоСледующегоВыстрела = скорострельность;
        воспроизвести.Shoot();
    }

    если (времяДоСледующегоВыстрела > 0) {
        времяДоСледующегоВыстрела -= delta;
    }
}
```

### 🔘 Интерактивная кнопка UI

```ces
alHacerClick() {
    textoUI.text = сообщениеПриКлике;

```

## ⚙️ Глава 10: Оптимизация и лучшие практики

Чтобы твоя игра летала на 60 FPS даже на мобильных устройствах, следуй этим советам:

1. **Используй `delta`**: Всегда умножай свои движения на `delta`. Это гарантирует, что твоя игра будет работать с одинаковой скоростью и на мощном ПК, и на старом.
2. **Избегай `find()` в `обновить`**: Поиск объектов по имени — это медленно. Делай это в `начать` и сохраняй результат в переменную.
3. **Пулинг (Pooling)**: Вместо того чтобы уничтожать и создавать сотни пуль, попробуй использовать их повторно.
4. **Слои коллизий**: Настрой в параметрах проекта, какие объекты с какими сталкиваются, чтобы сэкономить ресурсы процессора.

## 🛠️ Глава 11: Решение проблем и FAQ

**В: Мой скрипт ничего не делает.**
О: Убедитесь, что первая строка — `ve motor;`, и скрипт назначен активному объекту на сцене.

**В: Инспектор не показывает мои переменные.**
О: Вы должны объявлять их с ключевым словом `publico` перед типом (например, `publico число скорость = 10;`).

**В: Могу ли я использовать стандартный JavaScript?**
О: Да! CES — это слой поверх JS. Вы можете использовать `Math.random()`, `Array.push()` и т. д.

**В: Как уничтожить текущий объект?**
О: Используйте `destruir(mtr);` или просто `destruir(materia);`.
