# 📜 Главное руководство по скриптам (CES) - Creative Engine

Добро пожаловать на фронтир творчества! В **Creative Engine** создание скриптов — это не препятствие, а ваша суперсила. Язык **CES (Creative Engine Script)** был разработан интуитивно понятным, мощным и, прежде всего, **более простым, чем вы думаете**.

Это руководство проведет вас за руку от вашего первого «Привет, мир!» до сложных систем профессионального уровня. Приготовьтесь воплотить свои идеи в жизнь!

---

## 🚀 1. Ваш первый шаг: Подключение к движку

Каждый великий проект начинается с одной простой строки. В CES мы говорим скрипту подключиться к жизненно важным функциям движка:

```ces
ve motor;
```
*Совет: Вы также можете использовать `go motor;`, если предпочитаете более динамичный тон. Выбор за вами!*

### Чем CES отличается от других?
В отличие от других движков, где вам нужно писать `this.transform.position.x`, в Creative Engine мы убрали бюрократию:
- **Без `this.`**: Доступ к свойствам объекта напрямую.
- **Без сложных префиксов**: Если у вашего объекта есть компонент `Здоровье`, просто напишите `zdorovye.currentHealth = 100`.
- **Многоязычность**: Предпочитаете `posicion` или `position`? Движок понимает оба варианта!

## 💎 2. Публичные переменные: Инспектор — ваш друг

Публичные переменные позволяют вам (или вашим дизайнерам) настраивать значения прямо в редакторе, не касаясь кода.

```ces
publico число скорость = 5;
publico текст сообщение = "Осторожно!";
publico булево этоГерой = истина;
publico Материя цель;           // Перетащите любой объект сюда
publico Спрайт иконка;         // Выберите изображение
publico Аудио звукВзрыва;      // Выберите звук
publico Префаб пуляПрефаб;     // Многоразовый объект
publico Сцена следующийУровень; // Целая сцена
```

## ⏱️ 3. Жизненный цикл: Сердце вашей игры

Ваш скрипт реагирует на автоматические события, которые происходят в ключевые моменты:

- **`начать()` / `alEmpezar()`**: Выполняется один раз при рождении объекта. Идеально подходит для настройки начальных значений.
- **`обновить(delta)` / `alActualizar(delta)`**: Сердце скрипта. Выполняется каждый кадр. `delta` — это точное время между кадрами, используйте его для плавности движения.
- **`actualizarFijo(delta)`**: Идеально подходит для тяжелой физики. Выполняется через равные промежутки времени.
- **`alHacerClick()`**: Активируется, когда пользователь касается объекта или кликает по нему.

## ⌨️ 4. Ввод и движение

Управлять персонажем так же естественно, как говорить:

```ces
обновить(delta) {
    // Простое горизонтальное движение
    если (teclaPresionada("d")) {
        posicion.x += скорость * delta;
        отразитьГ = ложь; // Смотрит вправо
    }
    если (teclaPresionada("a")) {
        posicion.x -= скорость * delta;
        отразитьГ = истина; // Смотрит влево
    }

    // Прыжок одним нажатием
    если (teclaRecienPresionada("Space") и estaTocandoTag("Ground")) {
        fisica.applyImpulse(новый Vector2(0, -12));
        воспроизвести.Salto(); // Мгновенно запускает анимацию "Salto"!
    }
}
```

## 📦 5. Справочник компонентов (Режим эксперта)

Движок автоматически создает быстрый доступ ко всем компонентам объекта. Вот мастер-список:

| Компонент | Доступ (псевдоним) | Ключевые функции |
| :--- | :--- | :--- |
| **Transform** | `posicion`, `позиция` | `x`, `y`, `rotacion`, `escala`, `mirarA(x,y)` |
| **Rigidbody2D** | `fisica`, `физика` | `applyForce(x,y)`, `applyImpulse(x,y)`, `velocity` |
| **SpriteRenderer**| `renderizadorDeSprite` | `color`, `opacity`, `spriteName` |
| **Animator** | `animador`, `аниматор` | `play(name)`, `stop()`, `crossfade(name, time)` |
| **Health** | `zdorovye`, `vida` | `damage(amount)`, `heal(amount)`, `isDead` |
| **AudioSource** | `sonido`, `audio` | `play()`, `stop()`, `volumen`, `bucle` |
| **Attack** | `ataque`, `atack` | `executeAttack(atk)`, `cooldown` |
| **ProgressBar** | `barra`, `uiPolosa` | `value`, `maxValue`, `materiaObjetivo` |

## 📡 6. Связь: Глобальные сообщения

Хотите, чтобы все враги погибли, когда босс побежден? Не ищите сложные ссылки, используйте **Сообщения**.

**У босса:**
```ces
alMorir() {
    broadcast("BossDefeated", { bonus: 500 });
}
```

**В любом другом скрипте:**
```ces
начать() {
    onReceive("BossDefeated", (data) => {
        imprimir("Победа! Бонус: " + data.bonus);
        destruir(mtr); // Объект самоликвидируется
    });
}
```

## 🪄 7. Магические функции и корутины

### ⏳ Корутины (`ждать`)
Приостановка выполнения без остановки игры. Идеально для последовательностей:
```ces
async начать() {
    imprimir("Запуск последовательности...");
    ждать(2);
    imprimir("Прошло 2 секунды!");
    воспроизвести.Explosion();
}
```

### 🔁 Временные циклы (`cada`)
Чистое создание периодических событий:
```ces
начать() {
    cada(3) { // Каждые 3 секунды
        create enemyPrefab;
        imprimir("Появился новый враг.");
    }
}
```

## 🍳 8. Книга рецептов (Cookbook)

### 🏃 Профессиональный двойной прыжок
```ces
ve motor;
publico число максПрыжков = 2;
число прыжковОсталось = 2;

обновить(delta) {
    если (estaTocandoTag("Ground")) {
        прыжковОсталось = максПрыжков;
    }

    если (teclaRecienPresionada("Space") и прыжковОсталось > 0) {
        fisica.velocity.y = -10; // Вертикальный импульс
        прыжковОсталось -= 1;
        воспроизвести.Salto();
    }
}
```

### 🎥 Плавная камера (Smooth Follow)
```ces
ve motor;
publico Материя цель;
publico число сглаживание = 0.125;

обновить(delta) {
    если (цель) {
        variable желаемаяПоз = { x: цель.posicion.x, y: цель.posicion.y };
        posicion.x += (желаемаяПоз.x - posicion.x) * сглаживание;
        posicion.y += (желаемаяПоз.y - posicion.y) * сглаживание;
    }
}
```

### 🎒 Простая система инвентаря
```ces
ve motor;
variable инвентарь = [];

alEntrarEnColision(otro) {
    если (otro.hasTag("Item")) {
        инвентарь.push(otro.nombre);
        imprimir("Подобрано: " + otro.nombre + ". Всего: " + инвентарь.length);
        destruir(otro);
    }
}
```

## ⚙️ 9. Под капотом: Транспилятор

Движок использует систему **умной транспиляции**. Это означает, что когда вы пишете на CES, движок в реальном времени переводит ваш код в высокопроизводительный оптимизированный JavaScript.

- **Безопасность**: Движок обнаруживает ошибки перед запуском игры.
- **Скорость**: Работает нативно в браузере без тяжелых слоев.
- **Гибкость**: Если вы эксперт, вы можете использовать любую функцию JavaScript внутри ваших CES-скриптов.
