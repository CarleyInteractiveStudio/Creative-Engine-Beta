# 📜 Основное руководство по скриптам (CES) - Creative Engine

Creative Engine использует **CES (Creative Engine Script)** — мощный язык, основанный на JavaScript, но упрощенный для создателей игр. Это руководство научит вас всему, от основ до продвинутых систем.

---

## 🚀 Основные понятия

### 1. Обязательный импорт
Каждый скрипт должен начинаться с инструкции для подключения к движку:
```ces
ve motor;
```

### 2. Прямой доступ (без префиксов)
В отличие от других движков, вам НЕ нужно писать `this.` или `mtr.` для доступа к компонентам объекта. Если у объекта есть `SpriteRenderer`, просто напишите `renderizadorDeSprite`.

### 3. Многоязычность по дизайну
Вы можете программировать, используя термины на испанском или английском языке как взаимозаменяемые. Движок понимает оба. Например, `fisica` — это то же самое, что и `rigidbody2D`.

---

## 💎 Публичные переменные (Инспектор)
Чтобы переменная появилась в Инспекторе редактора, используйте ключевое слово `publico`.

```ces
publico numero velocidad = 5;
publico texto nombreJugador = "Герой";
publico booleano esInvencible = falso;
publico Materia objetivo; // Появится поле для перетаскивания объектов
```

---

## 🛠️ Утилиты движка
- `buscar(nombre)`: Найти объект в сцене.
- `destruir(materia)`: Удалить объект.
- `lanzarRayo(origen, direccion, distancia, tag)`: 2D Raycasting.
- `estaTocandoTag(tag)`: Быстрое обнаружение столкновений.
- `instanciar(original, x, y)`: Клонировать существующий объект.
- `crear miPrefab`: Создать экземпляр префаба по имени.
- `solapamientoUI(mtrA, mtrB)`: Обнаружение столкновений между элементами интерфейса.
