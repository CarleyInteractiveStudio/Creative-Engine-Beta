# 📜 Руководство по скриптингу (CES) - Creative Engine

Creative Engine использует **CES (Creative Engine Script)** — мощный язык, основанный на JavaScript, но упрощенный для создателей игр.

---

## 🚀 Основные концепции

### 1. Обязательный импорт
Каждый скрипт должен начинаться с инструкции подключения:
```ces
двигатель motor;
```
*(Примечание: Вы также можете использовать `ve motor;`)*

### 2. Прямой доступ
Вам НЕ нужно писать `this.` или `mtr.` для доступа к компонентам. Просто пишите `renderizadorDeSprite`.

---

## 💎 Публичные переменные
Чтобы переменная появилась в Инспекторе, используйте `открытый`.

```ces
открытый число скорость = 5;
открытый текст имя = "Герой";
открытый булево активен = ложь;
открытый материя цель;
```

---

## ⏱️ События жизненного цикла

```ces
// Выполняется один раз при появлении объекта
начать() {
    log("Привет, мир!");
}

// Выполняется каждый кадр
обновить(delta) {
}
```

---

## 🪄 Специальные функции

### ⏳ Корутины (Ожидание)
```ces
начать() {
    ждать(3);
    log("3 секунды прошло!");
}
```

### 🎭 Прокси анимации и звука
```ces
reproducir.Caminar(); // Вызов по имени состояния
play.Jump();
```
