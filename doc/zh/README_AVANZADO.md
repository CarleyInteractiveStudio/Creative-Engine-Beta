# 🏗️ 高级指南：项目、场景与构建 - Creative Engine

本指南涵盖了资源管理、关卡设计和游戏最终发布的各个核心方面。

---

## 📂 1. 项目结构

Creative Engine 中的每个项目都保存在一个专用文件夹中：
- `/Assets`: 所有的图像、声音、视频和脚本。
- `/lib`: 扩展引擎的库文件夹 (.celib)。
- `project.ceconfig`: 技术设置文件（图层、标签、元数据）。
- `thumbnail.png`: 项目预览图像。

---

## 🎬 2. 场景管理 (.ceScene)

场景是包含物体和环境设置的独立世界。

### 基本操作
- **保存场景:** 使用 `Ctrl + S`。
- **切换场景:** 在浏览器中双击任何 `.ceScene` 文件。
- **场景缩略图:** 保存时，引擎会自动为图标截取屏幕截图。

---

## 📦 3. 导入与数据包 (.cep)

### 导入资源
1. **拖放:** 直接从您的电脑将文件拖到资源浏览器中。
2. **Spine (骨骼动画):** 支持以 `.json` 格式从 Spine 导入。

### 导出数据包
右键点击 `Assets` 中的任何文件夹，然后选择 **导出数据包**。这将创建一个 `.cep` 文件，便于在项目之间传输。

---

## 🏗️ 4. 构建系统 (Build)

构建会创建一个独立的 Web 包 (`.zip`)，随时可以托管在服务器上。

1. 转到 **文件 > 构建 (Build)**。
2. 选择起始场景。
3. 配置启动画面 (Splash Screens)。
4. 点击 "构建游戏"。
