# 📜 脚本大师指南 (CES) - Creative Engine

Creative Engine 使用 **CES (Creative Engine Script)**，这是一种基于 JavaScript 但为游戏开发者简化的强大语言。本指南将教您从基础到复杂系统的所有知识。

---

## 🚀 核心概念

### 1. 强制导入
每个脚本都必须以连接引擎的指令开始：
```ces
引擎 motor;
```
*(注意：您也可以使用 `ve motor;`，它们是别名)*

### 2. 直接访问（无前缀）
与其他引擎不同，您不需要编写 `this.` 或 `mtr.` 来访问对象的组件。如果对象具有 `SpriteRenderer`，只需编写 `精灵渲染器` 即可。

---

## 💎 公共变量（检查器）
要让变量出现在编辑器的检查器中，请使用 `公开` 关键字。

```ces
公开 数字 速度 = 5;
公开 文本 玩家名称 = "英雄";
公开 布尔值 是无敌的 = 假;
公开 物质 目标; // 将出现一个用于拖放对象的方框
公开 精灵 图标;
公开 音频 跳跃声音;
```

## ⏱️ 生命周期事件
这些是引擎在特定时刻自动调用的函数。

```ces
// 当对象在游戏中出现时执行一次
开始() {
    log("你好，世界！");
}

// 每帧执行一次（约每秒 60 次）
更新(delta) {
    // delta 是自上一帧以来经过的时间
}

// 以固定间隔执行（物理逻辑的理想选择）
actualizarFijo(delta) {
}

// 当点击对象时执行
onPointerClick() {
}
```

## ⌨️ 输入与移动
轻松控制您的角色。

```ces
更新(delta) {
    # 按键按下（保持）
    如果 (teclaPresionada("d")) {
        位置.x += 速度;
        水平翻转 = 假;
    }

    # 按键刚刚按下（单次脉冲）
    如果 (teclaRecienPresionada("Space") 且 estaTocandoTag("地面")) {
        物理.applyImpulse(新建 向量2(0, -10));
    }

    # 鼠标
    如果 (botonMouseRecienPresionado(0)) { // 0: 左键, 1: 中键, 2: 右键
        任何 鼠标位置 = obtenerPosicionMouse();
        log("点击位置: " + 鼠标位置.x + ", " + 鼠标位置.y);
    }
}
```

## 🪄 Creative Engine 特殊函数

### ⏳ 协程（等待）
暂停脚本逻辑而不冻结游戏。
```ces
开始() {
    log("开始倒计时...");
    等待(3);
    log("开始！");
}
```

### 🔁 定时循环（每个）
每隔 X 秒重复执行某些操作。
```ces
开始() {
    cada(1.5) {
        log("过去了一秒半");
        // 非常适合生成敌人或恢复生命值
    }
}
```
