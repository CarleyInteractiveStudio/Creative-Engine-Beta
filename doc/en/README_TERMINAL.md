# 📟 Terminal Commands - Creative Engine

The terminal is an advanced tool for debugging and controlling the engine via text commands. Access from **Window > Terminal**.

---

## 📂 File Management
- `ls [folder]`: List directory contents.
- `cd [folder]`: Change current directory in the terminal.
- `mkdir [name]`: Create a new folder.
- `cat [file]`: Display text file contents.

---

## 🔍 Object Inspection
- `find [name]`: Search for a Materia in the scene by its name and return its ID.
- `inspect [id]`: Show all properties and components of an object in JSON format.
- `log [message]`: Print a message to the editor's console.

---

## 🎮 Game Control
- `play`: Start the game.
- `stop`: Stop the game and restore the scene.
- `pause`: Pause or resume execution.
- `scene [path]`: Load a specific scene immediately.

---

## 🧪 Advanced Utilities
- `stats`: Show performance metrics (FPS, draw calls, memory).
- `clear`: Clear the terminal screen.
- `whoami`: Show active project info and engine version.
- `help`: List all available commands.
