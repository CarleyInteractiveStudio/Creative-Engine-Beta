# Creative Engine 🎨🚀 — Knowledge Center

Welcome to the definitive **Creative Engine** library! Our documentation has been massively expanded into a full technical encyclopedia. Whether you are an absolute beginner or an advanced developer, you will find ultra-detailed explanations of every corner of the engine.

---

## 📚 Documentation Sections (Encyclopedia)

### 📔 [The Ultra-Detailed Master Book](README_MASTER_BOOK.md)
**Your ideal starting point!** An epic guide for absolute beginners that explains the concepts of **Matters** and **Laws**, how to build worlds, the UI system, and how to use all visual tools without writing a single line of code.

### 🧩 [Master Guide to Components (Laws)](README_COMPONENTES.md)
An exhaustive dictionary of all the "Laws" you can apply. Includes parameter-by-parameter explanations for:
- Advanced Physics and Collisions.
- Precision Rendering (Sprites, Textures, Video).
- Artificial Intelligence and Vehicle Controllers.

### 🎨 [Master Guide to Visual Editors](README_EDITORES_VISUALES.md)
Master the powerful built-in tools with step-by-step tutorials:
- **Animation Graph:** State logic and Smart Mode.
- **Skeletal Animation:** Bones, Skinning, and IK.
- **Tilemap & Terrain:** Organic and block-based construction.
- **VidSpri:** Video-to-lightweight asset conversion.

### 📕 [The Scripting Master Book (CES)](README_SCRIPTING.md)
**For the code architects.** A technical manual exceeding 1000 lines that teaches you to program from scratch using the multilingual CES language, including recipes for RPG, Platformers, and Shooters.

### 🤖 [The Carl IA Manual (Autonomous Agent)](README_CARL_IA.md)
**Your development companion.** Learn how to delegate tasks to Carl, use deep planning mode, CHC, and autonomous creation commands.

### ⚙️ [Advanced Management & Publishing](README_AVANZADO.md)
Everything about engine architecture, performance optimization, Prefab management, and how to export your game for Web and Android (including Keystore signatures).

## 🚀 Where to start?

If you are new, we recommend following this "Zero to Hero" order:
1. Read the [**Ultra-Detailed Master Book**](README_MASTER_BOOK.md) to understand the engine's DNA.
2. Explore the [**Master Guide to Components**](README_COMPONENTES.md) to know your tools.
3. Check the [**Carl IA Manual**](README_CARL_IA.md) to learn how to build faster with AI help.
4. Open the editor and start bringing your ideas to life!
