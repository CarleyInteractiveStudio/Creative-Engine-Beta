Documentación de la API para Crear Librerías

Conceptos Básicos

Las librerías te permiten extender la funcionalidad del editor y del motor. Todo comienza con un único archivo JavaScript.

Estructura del Script

Tu script debe ser una función autoejecutable (IIFE) que interactúa con la API global CreativeEngine.API.

(function() {
    // Tu código va aquí...
})();

Registrar una Ventana

Para que tu librería aparezca en el menú "Ventana", debes registrarla. Esto se hace llamando a registrarVentana.

CreativeEngine.API.registrarVentana({
    nombre: "Mi Primera Librería",
    alAbrir: function(panel) {
        // Esta función se ejecuta cuando el usuario abre tu ventana.
        // El objeto 'panel' es tu lienzo para construir la UI.
        panel.agregarTexto("¡Hola, mundo!");
    }
});

API de Componentes de UI

Dentro de la función alAbrir, puedes usar el objeto panel para añadir elementos de interfaz.

panel.agregarTexto(texto, opciones)

Muestra un texto simple. Opcionalmente puedes pasarle un objeto de opciones para darle un tamaño de fuente específico, como { tamaño: 'grande' }.

panel.agregarTexto("Este es un texto normal.");
panel.agregarTexto("Este es un título.", { tamaño: 'grande' });

panel.agregarBoton(texto, alHacerClic)

Crea un botón. La función alHacerClic se ejecuta cuando el usuario presiona el botón.

panel.agregarBoton("Haz clic aquí", function() {
    // Es mejor usar los diálogos del motor
    window.Dialogs.showNotification("Aviso", "¡Botón presionado!");
});

panel.agregarInputTexto(etiqueta, opciones)

Crea un campo de texto con una etiqueta. Puedes especificar un callback alCambiar para reaccionar a la entrada del usuario.

panel.agregarInputTexto("Nombre:", {
    placeholder: "Escribe tu nombre...",
    alCambiar: function(valor) {
        console.log("El nuevo nombre es:", valor);
    }
});

panel.agregarSlider(etiqueta, opciones)

Crea un slider deslizable. Puedes definir min, max, step (incremento) y un valor inicial valor.

panel.agregarSlider("Velocidad:", {
    min: 0,
    max: 100,
    step: 1,
    valor: 50,
    alCambiar: function(valor) {
        console.log("Nueva velocidad:", valor);
    }
});

panel.agregarCheckbox(etiqueta, opciones)

Crea una casilla de verificación. Puedes definir si está marcada por defecto con marcado: true.

panel.agregarCheckbox("Activar Modo Turbo", {
    marcado: true,
    alCambiar: function(estaMarcado) {
        console.log("Modo Turbo activado:", estaMarcado);
    }
});

panel.agregarDropdown(etiqueta, items, opciones)

Crea un menú desplegable. items debe ser un array de strings.

panel.agregarDropdown("Dificultad:", ["Fácil", "Normal", "Difícil"], {
    alCambiar: function(opcionSeleccionada) {
        console.log("Dificultad elegida:", opcionSeleccionada);
    }
});

panel.agregarImagen(url, opciones)

Muestra una imagen. Puedes pasarle ancho y alto en las opciones.

panel.agregarImagen("https://via.placeholder.com/150", {
    ancho: "150px",
    alto: "150px"
});

panel.agregarVideo(url, opciones)

Incrusta un video. Funciona mejor con URLs de video directas o plataformas como YouTube.

// Nota: Puede que necesites una URL 'embed' para algunas plataformas.
panel.agregarVideo("https://www.youtube.com/embed/dQw4w9WgXcQ");

API de Layout

panel.agregarContenedor(opciones)

Crea un contenedor para agrupar otros elementos. Puedes anidarlos y definir su dirección ('vertical' u 'horizontal').

const contenedorHorizontal = panel.agregarContenedor({ direccion: 'horizontal' });
// Los elementos añadidos a 'contenedorHorizontal' se alinearán uno al lado del otro.
contenedorHorizontal.agregarBoton("Botón 1", () => {});
contenedorHorizontal.agregarBoton("Botón 2", () => {});

panel.agregarAreaScroll(opciones)

Crea un área con scroll. Todos los elementos que añadas a esta área estarán dentro de un contenedor desplazable.

const areaScroll = panel.agregarAreaScroll({ alto: '200px' });
for (let i = 0; i < 20; i++) {
    areaScroll.agregarTexto(`Elemento número ${i + 1}`);
}

API de Runtime (Acceso desde Scripts .ces)

Si marcaste la casilla "Permitir acceso a sus funciones desde scripts" al crear la librería, tu script debe devolver un objeto. Las funciones dentro de este objeto estarán disponibles en los scripts .ces.

Estructura del Script de Runtime

El script debe devolver un objeto cuyas claves son los nombres de las funciones que quieres exponer.

// Dentro de tu archivo .js
return {
    saludar: function(nombre) {
        return "Hola, " + nombre + "!";
    },
    sumar: function(a, b) {
        return a + b;
    }
};

Uso en un Script .ces

Para usar estas funciones, primero importa la librería con go "NombreDeLaLibreria" y luego llama a las funciones directamente.

// Dentro de un archivo .ces
go "MiLibreriaDePrueba"

public star() {
    variable saludo = saludar("Mundo");
    consola.imprimir(saludo); // Imprime: "Hola, Mundo!"

    variable resultado = sumar(5, 3);
    consola.imprimir(resultado); // Imprime: 8
}
