Documentación de la API para Crear Librerías

Conceptos Básicos

Las librerías te permiten extender la funcionalidad del editor y del motor. Los archivos se guardan en la carpeta /lib de tu proyecto, donde encontrarás un README.md con más información.

Estructura del Script

Tu script debe ser una función autoejecutable (IIFE) que interactúa con la API global CreativeEngine.API.

(function() {
    // Tu código va aquí...
})();

Registrar una Ventana

Para que tu librería aparezca en el menú "Ventana", debes registrarla. Puedes personalizar el estilo y tamaño inicial.

CreativeEngine.API.registrarVentana({
    nombre: "Mi Herramienta Pro",
    estilo: "carl", // Opciones: "carl" (cristal), "moderno" (limpio)
    ancho: 500,
    alto: 400,
    alAbrir: function(panel) {
        panel.texto("¡Bienvenido a la nueva API!");
        panel.boton("OK", () => console.log("Clic!"));
    }
});

API de UI Simplificada

Usa estas palabras clave cortas para construir tu interfaz rápidamente dentro de alAbrir.

panel.texto(contenido, opciones)

Añade texto simple. Opciones: { color, negrita, tamano }.

panel.boton(etiqueta, clic, opciones)

Crea un botón. Opciones: { ancho, alto, color }.

panel.boton("Ejecutar Acción", () => {
    window.Dialogs.showNotification("Aviso", "¡Acción ejecutada!");
}, { ancho: '100%', alto: '40px', color: '#2ecc71' });

panel.input(etiqueta, opciones)

Campo de texto. Opciones: { inicial, placeholder, alCambiar }.

panel.numero(etiqueta, opciones)

Campo numérico. Opciones: { inicial, min, max, paso, alCambiar }.

panel.desplegable(etiqueta, items, opciones)

Menú de selección. Opciones: { inicial, alCambiar }.

panel.checkbox(etiqueta, inicial, alCambiar)

Casilla de verificación.

panel.slider(etiqueta, opciones)

Barra deslizable. Opciones: { inicial, min, max, paso, alCambiar }.

Layout y Organización

Divide tu ventana fácilmente usando filas, columnas y áreas de scroll con callbacks.

panel.fila(opciones, callback)

Organiza elementos horizontalmente.

panel.fila({ gap: '20px' }, (f) => {
    f.boton("Izquierda", () => {});
    f.boton("Derecha", () => {});
});

panel.columna(opciones, callback)

Organiza elementos verticalmente (comportamiento por defecto).

panel.scroll(opciones, callback)

Crea un área con scroll infinito. Opciones: { alto }.

panel.scroll({ alto: '150px' }, (s) => {
    for(let i=0; i<50; i++) s.texto("Línea " + i);
});

panel.separador()

Añade una línea divisoria horizontal.

API de Runtime (Acceso desde Scripts .ces)

Si marcaste la casilla "Permitir acceso a sus funciones desde scripts" al crear la librería, tu script debe devolver un objeto. Las funciones dentro de este objeto estarán disponibles en los scripts .ces.

Estructura del Script de Runtime

El script debe devolver un objeto cuyas claves son los nombres de las funciones que quieres exponer.

// Dentro de tu archivo .js
return {
    saludar: function(nombre) {
        return "Hola, " + nombre + "!";
    },
    sumar: function(a, b) {
        return a + b;
    }
};

Uso en un Script .ces

Para usar estas funciones, primero importa la librería con go "NombreDeLaLibreria" y luego llama a las funciones directamente.

// Dentro de un archivo .ces
go "MiLibreriaDePrueba"

public star() {
    variable saludo = saludar("Mundo");
    consola.imprimir(saludo); // Imprime: "Hola, Mundo!"

    variable resultado = sumar(5, 3);
    consola.imprimir(resultado); // Imprime: 8
}

Intenta mantener los FPS estables usando un bucle de espera activa. ADVERTENCIA: Esto aumentará el uso de CPU y el consumo de RAM.

Limita los FPS para ahorrar batería y recursos. Usa 0 para sin límite.

El motor activará optimizaciones extremas si el rendimiento cae cerca de este valor.

Nota: Esta cantidad mínima no está garantizada, pero activará una optimización profunda para intentar mantener la fluidez.

Define el límite de memoria y red para el motor. Si se supera el 80% de RAM, el motor intentará liberar recursos. El límite de red avisará cuando se consuma más internet de lo permitido.
